# Small exercises

Solve each twice in the hour: about 25 minutes per approach, then 10 minutes of comparison. See [pacing](../01-shared/01-small-pacing.md) and the [comparison rubric](../01-shared/03-comparison-rubric.md).

| # | Exercise | Minimum scope | Interview judgment | Status |
| --- | --- | --- | --- | --- |
| 01 | [Live poll](./01-live-poll/) | Single-question poll, votes, results | Define “one vote per person” without accounts | stub |
| 02 | [URL shortener](./02-url-shortener/) | Short links, redirect, visit counts | Validate destinations, handle unknown links | stub |
| 03 | [Feedback board](./03-feedback-board/) | Suggestions, upvotes, sort by popularity | Correct counts, tie-breaking | stub |
| 04 | [Office-hours queue](./04-office-hours-queue/) | Join queue, see position, instructor marks helped | Ordering, duplicate submissions | **written** |
| 05 | [Expense splitter](./05-expense-splitter/) | Participants, expenses, equal-share balances | Currency rounding, explaining balances | stub |
| 06 | [Searchable inventory](./06-searchable-inventory/) | Search seeded catalog, adjust stock | Server validation, no negative stock | stub |
| 07 | [Flashcard practice](./07-flashcard-practice/) | Add cards, reveal, mark, save totals | Temporary UI state versus persisted progress | stub |
| 08 | [Event RSVP](./08-event-rsvp/) | One event, RSVP and cancel, remaining capacity | Server-enforced capacity, final place | stub |
