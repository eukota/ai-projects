# Extensions

Use only if a group finishes early. Each is independent.

- **Leave the queue:** a waiting student can remove themselves; positions update.
- **Instructor view:** a separate view listing questions with the front entry highlighted.
- **Estimated wait:** show a rough wait using a fixed minutes-per-student constant. Ask how they would explain the estimate to a student.
- **Auto-refresh:** the student’s position updates by polling without a manual refresh.
- **Return to queue:** a helped student can rejoin at the back. Ask how this interacts with the duplicate rule.
