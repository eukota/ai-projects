# Student prompt

A small team wants to request reports without waiting on the page while they run.

## Request

Build a web app where:

- A user submits a report job from a form.
- The page lists jobs and shows each one's status as it changes.
- When a job is done, the user can retrieve its result.

The report is simulated: a worker waits a few seconds and produces generated output. The app has a browser UI and an HTTP API with in-memory or SQLite storage. A starter app is optional.

## What we want to see

Spend the first 10 minutes clarifying and planning: questions you would ask, assumptions, job record shape, statuses, endpoints. Then build one complete flow, test it, and be ready for a change request.

You have about an hour. Work as you would in an AI-assisted interview: direct the AI, read its output critically, explain your decisions, and verify the result.
