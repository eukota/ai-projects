# Medium exercises

Solve each once, then introduce a follow-up change. See [pacing](../01-shared/02-medium-pacing.md).

| # | Exercise | Minimum scope | Follow-up change | Status |
| --- | --- | --- | --- | --- |
| 01 | [Appointment booking](./01-appointment-booking/) | One provider’s fixed slots; book and cancel | Two sessions book the same slot | **written** |
| 02 | [Support-ticket desk](./02-support-ticket-desk/) | Tickets, priorities, open/active/resolved | Require resolution note before closing | stub |
| 03 | [Small checkout](./03-small-checkout/) | Products, cart, order with simulated payment | Price or stock changes after item enters cart | stub |
| 04 | [Room reservation](./04-room-reservation/) | Reserve by date and time, daily agenda | Reject overlaps, allow back-to-back | stub |
| 05 | [CSV import preview](./05-csv-import-preview/) | Upload known CSV, preview, import valid rows | No duplicates on re-upload | stub |
| 06 | [Approval workflow](./06-approval-workflow/) | Submit expense, approve or reject with comments | Renewed approval when amount changes | stub |
| 07 | [Chat room](./07-chat-room/) | One room, history, display names, polling | No duplicates when a failed send is retried | stub |
| 08 | [Background-job dashboard](./08-background-job-dashboard/) | Submit simulated job, status, result | Failure and retry with history preserved | stub |
