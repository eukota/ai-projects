# Student prompt

A small clinic wants to let patients book time with one provider.

## Request

Build a web app where:

- The page shows the provider’s available time slots for the day.
- A user picks a slot, enters a name, and books it.
- A booked slot shows as taken.
- A user can cancel their appointment, which frees the slot.

The app has a browser UI and an HTTP API with in-memory storage. A starter app is provided.

## What we want to see

Spend the first 10 minutes clarifying and planning: questions you would ask, assumptions, record shape, endpoints. Then build one complete flow, test it, and be ready for a change request.

You have about an hour. Work as you would in an AI-assisted interview: direct the AI, read its output critically, explain your decisions, and verify the result.
