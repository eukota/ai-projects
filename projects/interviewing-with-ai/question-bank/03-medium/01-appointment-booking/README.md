# Appointment booking

A single provider has fixed time slots. Users book and cancel appointments.

## Minimum scope

Display one provider’s fixed slots; book and cancel appointments.

## Follow-up change

Handle two browser sessions attempting to book the same slot. This exposes any check-then-write assumption made during the build.

## Timing

Solve once, then change. See [medium pacing](../../01-shared/02-medium-pacing.md): 10 clarify and plan, 30 build, 15 test and revise, 5 tradeoffs.
