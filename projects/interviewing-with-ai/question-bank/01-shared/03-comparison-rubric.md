# Comparison rubric

Use for the 10-minute comparison after two small-exercise attempts. Score each attempt on the same four dimensions and discuss the differences, not the totals.

| Dimension | Questions to ask |
| --- | --- |
| Correctness | Which acceptance criteria pass? Which edge cases were found by review versus by luck? |
| Clarity | Can the student explain every decision in the code? Are requirements and assumptions written down? |
| Time | When did the first working flow appear? Where did time go: prompting, waiting, debugging? |
| Instructor intervention | How many times, and at which point, did the instructor need to redirect? |

## Prompts for discussion

- Which approach surfaced the ambiguity in the interview-judgment item sooner?
- Where did the student accept AI output without reading it?
- What would you do first in a real interview given 25 minutes?
